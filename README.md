# MNIST Handwritten Digit Classifier

## Project Overview

This project focuses on building an end-to-end handwritten digit classification system using Python and PyTorch.

The goal is to develop a neural network capable of recognizing handwritten digits (0–9) from the MNIST dataset, which contains 28×28 grayscale images of handwritten numbers.

Rather than relying on prebuilt machine learning solutions, the project emphasizes independently implementing and understanding the complete machine learning workflow, from data preprocessing and neural network training to model evaluation and inference.

## Project Objectives

- Load, explore, and preprocess the MNIST dataset.
- Design and implement a neural network using PyTorch.
- Build a training and evaluation pipeline.
- Measure model accuracy and analyze incorrect predictions.
- Save and load trained models for inference.
- Write maintainable, modular, and testable Python code.
- Benchmark inference performance and investigate CPU/GPU execution.
- Explore optional deployment through a REST API.

## Technologies

- **Language:** Python
- **ML Framework:** PyTorch
- **Dataset:** MNIST (TorchVision)
- **Development Environment:** PyCharm
- **Version Control:** Git and GitHub

## Development Approach

This project is being developed incrementally as an independent machine learning engineering exercise. Each milestone emphasizes understanding the underlying concepts, implementing functionality independently, and validating results through testing.

The long-term objective is to develop practical skills in machine learning engineering, neural network implementation, software engineering, and ML inference systems.
